# Keys.so MCP

**Разберите SEO конкурентов прямо в диалоге с ассистентом.**

Узнайте, по каким запросам продвигается конкурент, изучите его объявления и источники обратных ссылок. Keys.so MCP передаёт отчёты сервиса вашему ассистенту: можно уточнять вопросы по исходным данным и развивать исследование прямо в чате.

[Установка](#установка) · [Подключение к ассистенту](#подключение-к-ассистенту) · [Issues](https://github.com/zai-one/keysso-mcp/issues)

Например, попросите ассистента:

> Получи отчёт по органическим запросам example.com. Сгруппируй полученные запросы по темам и предложи, какие группы стоит изучить подробнее.

## Что можно сделать

| Задача | Возможности MCP |
|---|---|
| Разобрать конкурента | Обзор домена, органические запросы, конкурирующие сайты и отчёты по посадочным страницам. |
| Изучить рекламу | Доступные отчёты по объявлениям, рекламным запросам и истории рекламы. |
| Исследовать ссылки | Обратные ссылки, ссылающиеся домены, анкоры и страницы. |

## Установка

Нужны **Python 3.12–3.14** и [uv](https://docs.astral.sh/uv/getting-started/installation/). Можно клонировать проект через Git или [скачать ZIP](https://github.com/zai-one/keysso-mcp/archive/refs/heads/main.zip). Для ZIP откройте распакованный каталог и пропустите первые две команды.

Нужны API-токен Keys.so и доступ к нужным отчётам. Настройщик сохраняет токен в приватном локальном файле.

```sh
git clone https://github.com/zai-one/keysso-mcp.git
cd keysso-mcp
uv sync --frozen
uv run --frozen python scripts/configure.py
uv run --frozen keysso-mcp --config mcp.local.json --check-config
```

Настройщик создаёт локальную конфигурацию и сохраняет секреты в приватных файлах. Если конфигурация уже существует, он не перезапишет её. `--check-config` проверяет локальные настройки; доступ к аккаунту проверяется первым запросом ниже.

## Подключение к ассистенту

Добавьте конфигурацию в MCP-клиент, использующий раздел `mcpServers` (например, Claude Desktop или Cursor). Замените `/ABSOLUTE/PATH/` своим абсолютным путём; на Windows в JSON можно использовать `D:/Tools/`.

```json
{
  "mcpServers": {
    "keysso": {
      "command": "uv",
      "args": [
        "--directory",
        "/ABSOLUTE/PATH/keysso-mcp",
        "run",
        "--frozen",
        "keysso-mcp",
        "--config",
        "/ABSOLUTE/PATH/keysso-mcp/mcp.local.json"
      ]
    }
  }
}
```

Клиент сам запускает MCP-сервер. После обновления списка инструментов отправьте первый запрос. Для другого формата конфигурации используйте те же `command` и `args`; `uv` должен быть доступен процессу клиента.

### Первый запрос

> Открой keysso://reports и покажи доступные отчёты. Затем получи обзор домена моего сайта.

Каталог покажет поддерживаемые отчёты и параметры без запроса к API. Запрос по домену вернёт данные Keys.so с вашим токеном. Укажите домен и нужную базу или регион для анализа.

Если инструменты не появились, проверьте абсолютный путь, доступность `uv` и результат `--check-config`. Для ошибки доступа проверьте учётные данные и права аккаунта. [Подробная установка и диагностика](INSTALL.md).

## Управление доступом и ограничения

Один вызов инструмента запрашивает одну страницу отчёта. Для более полной выборки попросите ассистента пройти следующие страницы: одна страница не описывает весь рынок или ссылочный профиль.

Сервер предоставляет отчёты только для чтения. Доступные данные и лимиты запросов зависят от аккаунта Keys.so. Подробнее: [лимиты и настройка доступа](docs/RUNTIME.md).

Для работы по сети предусмотрен HTTP с проверкой токенов. [Настройка HTTP](INSTALL.md#http), [конфигурация и права](docs/RUNTIME.md), [подключение Python-пакета](INSTALL.md#python-package-and-platform-integration).
