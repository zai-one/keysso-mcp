# Keys.so MCP

**Разберите SEO конкурентов прямо в диалоге с ассистентом.**

> MCP-сервер для Keys.so (по умолчанию только чтение): домены конкурентов, органические и платные запросы, страницы, архив объявлений, ссылки и AI-трекер (GEO).

Узнайте, по каким запросам продвигается конкурент, изучите его объявления и источники обратных ссылок. Keys.so MCP передаёт отчёты сервиса вашему ассистенту: можно уточнять вопросы по исходным данным и развивать исследование прямо в чате.

[Установка](#установка) · [Подключение к ассистенту](#подключение-к-ассистенту) · [Issues](https://github.com/zai-one/keysso-mcp/issues)

Например, попросите ассистента:

> Получи отчёт по органическим запросам example.com. Сгруппируй полученные запросы по темам и предложи, какие группы стоит изучить подробнее.

## Что можно сделать

| Задача | Возможности MCP |
|---|---|
| Разобрать конкурента | Обзор домена, органические запросы, конкурирующие сайты и отчёты по посадочным страницам. |
| Изучить рекламу | Доступные отчёты по объявлениям, рекламным запросам и истории рекламы. |
| Исследовать ссылки | Обратные ссылки, ссылающиеся домены, анкоры и страницы. |
| Поднять архив рекламы | Помесячный архив рекламы Яндекса по домену, объявлению или фразе (`month=ГГГГ-ММ`), а также сводка по фразе и похожие фразы. |
| Следить за ИИ-ответами (GEO) | `keysso_ai_tracker` читает ваши проекты ИИ-трекера: упоминания, цитируемость, видимость бренда и конкурентов, источники и ответы на промпты. Ничего не создаёт, не запускает и не удаляет. |

## Почему этот MCP

- Ленивая загрузка инструментов (опционально): `KEYSSO_TOOL_LOADING=lazy` (или выбор в мастере настройки) — старт с небольшим ядром, наборы включаются по запросу; см. [Ленивая загрузка инструментов](#ленивая-загрузка-инструментов).
- По умолчанию только чтение: наборы по умолчанию ничего не создают, не запускают и не удаляют. Opt-in наборы (`jobs`, `monitoring`, `api`) могут запускать задачи, расходующие лимиты, и менять проекты мониторинга; каждый такой вызов требует `approval_id`, подтверждённого оператором вне MCP (`keysso-approval --approval-id ID --digest D --accept`, одноразовый, 30 минут).
- Небольшой набор инструментов маршрутизирует к документированному каталогу отчётов (`keysso://reports`), лимиты и фильтр полей сокращают ответы.
- Наборы инструментов (meta, reports, ai_tracker; opt-in jobs, monitoring и api: сбор семантики, кластеризация, мониторинг позиций, документированные `tools/*`, `wordstat/*`, `serp/*`), инструкции-роутер по интентам (RU/EN → инструмент, skill, гайд) с eval-тестом, skills и промпты.
- У другого Keys.so MCP на GitHub ([perfilev/keys-so-mcp](https://github.com/perfilev/keys-so-mcp), 21 инструмент) нет тестов, CI и проверки обновлений.

## Ленивая загрузка инструментов

Ленивая загрузка инструментов (опционально): `KEYSSO_TOOL_LOADING=lazy` стартует с небольшим ядром и `keysso_enable_toolsets`, остальные наборы включаются по запросу (`tools/list_changed`). Стоимость старта (tools/list + instructions, ≈символы/4): eager ≈1726 токенов, lazy ≈1013 токенов (−41%). По умолчанию `eager` — без изменений; если клиент не поддерживает `tools/list_changed`, оставьте `eager` или переподключитесь после включения. Область: включение действует в пределах MCP-сессии (session visibility FastMCP), включённые одним клиентом наборы не видны другому. HTTP-транспорт здесь stateless (каждый запрос — отдельная сессия), поэтому включение там не сохраняется: для общего HTTP используйте `eager` или `KEYSSO_TOOLSETS`.

Клиенты и `notifications/tools/list_changed` (проверено по официальной документации, changelog или заявлениям мейнтейнеров, 2026-10):

| Клиент | `tools/list_changed` | Источник |
|---|---|---|
| Claude Code | Да (интерактивно: tools, prompts, resources; `-p`/Agent SDK: только tools) | [docs: Dynamic tool updates](https://code.claude.com/docs/en/mcp) |
| VS Code (GitHub Copilot) | Да (dynamic tool discovery); новые инструменты могут стать доступны агенту только со следующего хода | [docs](https://code.visualstudio.com/api/extension-guides/ai/mcp), [#303012](https://github.com/microsoft/vscode/issues/303012) |
| Gemini CLI | Да (обновляет реестр инструментов) | [PR #14375](https://github.com/google-gemini/gemini-cli/pull/14375), [PR #21050](https://github.com/google-gemini/gemini-cli/pull/21050) |
| Cursor | Ненадёжно: регрессия в 3.12.x подтверждена командой Cursor; после включения перезапустите Cursor | [forum](https://forum.cursor.com/t/mcp-server-regression-does-not-reload-tools-disconnect-does-nothing-ignores-mcp-json-changes-etc/166216) |
| Claude Desktop, Windsurf, Codex CLI, Cline, Zed, Continue | Не проверено: официальных данных нет; используйте `eager` или переподключитесь после включения | — |

## Поддержка и обновления

- Проект активно поддерживает ZAI.ONE: текущая версия 0.5.0; изменения в [CHANGELOG.md](CHANGELOG.md) и [Releases](https://github.com/zai-one/keysso-mcp/releases).
- Встроенная проверка обновлений: попросите ассистента вызвать `keysso_check_update` (публичный GitHub API, без учётных данных, с кэшем; ничего не устанавливается автоматически; отключение: `KEYSSO_DISABLE_UPDATE_CHECK=1`).
- Следует актуальным практикам MCP: аннотации инструментов (read-only / destructive), наборы инструментов и режим только чтения, `instructions` сервера, промпты и ресурсы, структурированные ошибки с подсказками, секреты не попадают в ответы, бюджет токенов описаний проверяется в тестах.
- CI прогоняет тесты на Linux и Windows для каждого pull request.

## Установка

Хотите установить готовый пакет? [Установка релиза и создание конфигурации клиента](INSTALL.md#install-a-release-package) работают без клонирования исходников.

Нужны **Python 3.12–3.14** и [uv](https://docs.astral.sh/uv/getting-started/installation/). Можно клонировать проект через Git или [скачать ZIP](https://github.com/zai-one/keysso-mcp/archive/refs/heads/main.zip). Для ZIP откройте распакованный каталог и пропустите первые две команды.

Нужны API-токен Keys.so и доступ к нужным отчётам. Настройщик сохраняет токен в приватном локальном файле.

```sh
git clone https://github.com/zai-one/keysso-mcp.git
cd keysso-mcp
uv sync --frozen
uv run --frozen python scripts/configure.py
uv run --frozen keysso-mcp --config mcp.local.json --check-config
```

Настройщик создаёт локальную конфигурацию и сохраняет секреты в приватных файлах. Если конфигурация уже существует, он не перезапишет её. `--check-config` проверяет локальные настройки; доступ к аккаунту проверяется первым запросом ниже.

## Подключение к ассистенту

Добавьте конфигурацию в MCP-клиент, использующий раздел `mcpServers` (например, Claude Desktop или Cursor). Замените `/ABSOLUTE/PATH/` своим абсолютным путём; на Windows в JSON можно использовать `D:/Tools/`.

```json
{
  "mcpServers": {
    "keysso": {
      "command": "uv",
      "args": [
        "--directory",
        "/ABSOLUTE/PATH/keysso-mcp",
        "run",
        "--frozen",
        "keysso-mcp",
        "--config",
        "/ABSOLUTE/PATH/keysso-mcp/mcp.local.json"
      ]
    }
  }
}
```

Клиент сам запускает MCP-сервер. После обновления списка инструментов отправьте первый запрос. Для другого формата конфигурации используйте те же `command` и `args`; `uv` должен быть доступен процессу клиента.

### Первый запрос

> Открой keysso://reports и покажи доступные отчёты. Затем получи обзор домена моего сайта.

Каталог покажет поддерживаемые отчёты и параметры без запроса к API. Запрос по домену вернёт данные Keys.so с вашим токеном. Укажите домен и нужную базу или регион для анализа.

Если инструменты не появились, проверьте абсолютный путь, доступность `uv` и результат `--check-config`. Для ошибки доступа проверьте учётные данные и права аккаунта. [Подробная установка и диагностика](INSTALL.md).

## Управление доступом и ограничения

`keysso_domain_report` собирает запросы, конкурентов, страницы или ссылки; `keysso_compare_domains` помогает искать пересечения и пробелы между доменами. Каждый инструмент может пройти до пяти страниц и вернуть JSON или CSV с источником и признаком полноты. Прежний `keys_so_query` по-прежнему запрашивает одну страницу. [Примеры отчётов и ограничения](docs/REPORTS.md).

Попробуйте: «Выгрузи в CSV запросы конкурента, исключив мой домен. Покажи, полная ли получилась выборка».

### Обновления

`keysso_check_update` сравнивает установленную версию с последним [релизом на GitHub](https://github.com/zai-one/keysso-mcp/releases) и возвращает ссылку на релиз и команду `uv tool install --force ...`. Сам MCP ничего не устанавливает и не тратит лимиты Keys.so. Результат кешируется на 24 часа рядом с базой состояния; если в кеше есть более новая версия, сервер один раз упомянет её в инструкциях. После неудачного запроса следующий выполняется не раньше чем через 30 минут, а `force_refresh` — не чаще раза в минуту. `KEYSSO_DISABLE_UPDATE_CHECK=1` отключает и сетевой запрос инструмента, и обновление кеша при запуске.

Сервер предоставляет отчёты только для чтения. Доступные данные и лимиты запросов зависят от аккаунта Keys.so. Подробнее: [лимиты и настройка доступа](docs/RUNTIME.md).

Для работы по сети предусмотрен HTTP с проверкой токенов. [Настройка HTTP](INSTALL.md#http), [конфигурация и права](docs/RUNTIME.md), [подключение Python-пакета](INSTALL.md#python-package-and-platform-integration).
